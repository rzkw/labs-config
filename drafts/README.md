# Labs Config

Configuration files for dev laptop and laboratory environments.

## Repository Structure

The repository is organized into the following standardized directories:

- `ansible/`: Comprehensive Ansible automation including playbooks, inventories, and templates.
- `docker/`: Docker daemon and container configurations.
- `host-configs/`: Operating system level configurations (e.g., GRUB, Fail2Ban).
- `laptop-settings/`: Dotfiles and settings for local development machines.
- `nginx/`: Nginx server and site-specific configurations.
- `resources/`: Curated links, reads, and server-specific resources.
- `rsync-backup/`: Systemd services and scripts for rsync-based backups.
- `scripts/`: Local utility and backup scripts.
- `ssh/`: SSH daemon security and configuration settings.
- `troubleshooting/`: Documentation for resolving common lab issues.
- `vendor-docs/`: Local copies of important third-party documentation.
